# si-tools

Tools website for Shurley Industries, deployed to GitHub Pages at `tools.shurley.industries`.

## Included tools

- Calculator
- Graphing calculator
- SI Possession Tracker (SIPT)
- Unit Converter
- Password / Passphrase Generator
- QR Code™ Generator

## Navigation

The root landing page links to all available tools, and each utility page includes a back link to return to the main tools page.
